# How to log CCS values for a paper:

1. Go to the 'papers' tab
  - if you have a paper in mind, search its DOI to check if it already exists in the database
    - if the papers has not in the database, you will be prompted to add it
    - go to 'Add entry' to log CCS values for the paper
  - if you would like to choose a paper from the database at random then click 'choose a paper for me'
2. Log a CCS value
  - most papers containing CCS values contain values corresponding to more than one protein - each protein should be logged separately
  - to save you writing the same text several times, you can click on any paper in the database and use it as a template for the next entry
  - most of the entry fields are self-explanatory, here is a brief guide to the ones that aren't:
    - Native? - Here you should put 'Yes' if the paper claims to be reporting native ion mobility data even if you think that the conditions they have used are not native.
    - Subunits - For a monomeric protein, put 1
    - Measurement Conditions - Generally I have been copying and pasting the relevant paragraph of the methods section of the paper - this field is for instrument details, parameters etc.
    - Sample Description - Here I want to know what the protein was dissolved in and what the concentration was - more/less detail is provided in different papers so to keep it simple you can copy and paste the relevant part of the methods section.
    - Sample Details Tab - For the supplier details, PDB ID and the measured mass, only report these if they are reported in the paper - for the others, if you have time then give your best guess regardless. For example, if the paper reports CCS values for ubiquitin but doesn't provide a sequence or Uniprot ID, find the corresponding Uniprot entry and use it to give a sequence and sequence mass.
    - CCS Measurements Tab - Most of the time, papers provide CCS data corresponding to individual charge states - if this is the case then fill in the table at the bottom. Only give an error if the paper provides one. If you need to read the CCS value from a graph then indicate this. If a global CCS value is provided then there is also a section to report this and the charge states included in that global value.
